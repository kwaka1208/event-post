# EventPost 再設計

クローズドなグループのためのイベント管理システムとして作り直す。トップページ以外は、承認された Google アカウントだけが見られる。

## 決めたこと

| 項目 | 方針 |
|---|---|
| グループの数 | 1 サイト 1 グループ。グループごとに Firebase のプロジェクトを用意してデプロイする |
| グループの作成 | デプロイ後、最初にログインした人が `/setup` で作る。作った人が特権管理者になる。2 つ目は作れない |
| 画面 | Vite＋React＋React Router＋TanStack Query の SPA（`web/`） |
| ホスティング | GitHub Pages（ほかのサイトと運用を揃える）。Firebase の Web 設定はビルド時に環境変数 `VITE_FIREBASE_*` で埋め込む。どのパスでも画面を出せるよう、`index.html` を `404.html` に複製する。サブパスは環境変数 `BASE_PATH` で渡す |
| データ | Cloud Firestore。アクセス制御はセキュリティルールで行う。無料の Spark プランで動かす（Cloud Functions は使わない） |
| メール | GitHub Actions が毎時 Firestore を見て、Gmail から送る。最大 1 時間ほど遅れて届く |
| 申込データ | 自動では削除しない（マイページで過去の参加を見せるため） |

## 役割と権限

役割は `owner`（特権管理者）、`admin`（管理者）、`member`（参加者）の 3 つ。`owner` はグループを作った 1 人だけ。

| 操作 | 未登録 | 参加者 | 管理者 | 特権管理者 |
|---|:-:|:-:|:-:|:-:|
| トップページを見る | ○ | ○ | ○ | ○ |
| 参加を申し込む | ○ | | | |
| イベントを見て申し込む（これから・過去） | | ○ | ○ | ○ |
| マイページを見る | | ○ | ○ | ○ |
| 申し込みを参加者として承認する・削除する | | | ○ | ○ |
| 申し込みを管理者として承認する | | | | ○ |
| イベントを作成・編集する | | | ○ | ○ |
| 参加者を削除する・メールを送る | | | ○ | ○ |
| 管理者を削除する・役割を変える | | | | ○ |
| グループの設定を変える | | | | ○ |

- 特権管理者は削除できない
- グループから削除された人は、もう一度参加を申し込める

## データ（Firestore）

| パス | 中身 | 読める人 |
|---|---|---|
| `group/profile` | グループ名、説明、特権管理者の名前と uid | 誰でも |
| `members/{uid}` | 役割、本名、ニックネーム、メールアドレス、参加日時 | 本人と管理者 |
| `applications/{uid}` | 本名、ニックネーム、申し込み理由、メールアドレス、申込日時、通知の送信日時 | 本人と管理者 |
| `events/{id}` | タイトル、本文（Markdown）、日時、会場、住所、定員、締切、公開状態、申込数 | メンバー（下書きは管理者だけ） |
| `events/{id}/registrations/{uid}` | イベントへの申込 | 本人と管理者 |
| `mails/{id}` | 管理者が書いたメール（宛先、件名、本文、送信状況） | 管理者 |

- グループの作成は 1 回の書き込みで行う（`group/profile` と自分の `members` を同時に作る）
- 承認も 1 回の書き込みで行う（`members` を作り、`applications` を消す）
- イベントへの申込とキャンセルは、`registrations` の作成・削除と申込数の ±1 を同時に書く（定員をルールで守るため）
- マイページは `registrations` を collectionGroup で検索して、自分の分を取り出す

## 画面

| パス | 画面 | 見られる人 |
|---|---|---|
| `/` | トップページ（グループ名、特権管理者の名前、説明、Google でログイン） | 誰でも |
| `/setup` | グループの作成 | グループがまだないときだけ |
| `/join` | 参加申し込み（本名、ニックネーム、理由）。送ったあとは「承認待ち」を表示 | 未登録 |
| `/events`、`/events/:id` | イベントの一覧（これから・過去）、詳細と申込 | メンバー |
| `/me` | マイページ（申し込んだイベント、参加したイベント） | メンバー |
| `/admin/applications` | 申し込み一覧（役割の選択、承認、削除） | 管理者 |
| `/admin/members` | メンバー一覧（削除、全員または選んだ人へのメール） | 管理者 |
| `/admin/events` | イベントの作成・編集 | 管理者 |
| `/admin/settings` | グループの設定 | 特権管理者 |

## メール（毎時の Actions）

- 新しい参加申し込み → 管理者全員に通知
- 承認 → 本人に通知
- イベントへの申込 → 受付メール
- 開催前日 → リマインド
- 管理者が画面で書いたメール → 指定した宛先へ

## 最初の版に入れないもの

- イベントごとの申込フォームの追加項目（旧版の `fields`）
- キャンセル待ち・抽選、決済
