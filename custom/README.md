# custom/

グループごとのファイルを置くフォルダです。本体を更新しても、このフォルダの中は変わりません。

| ファイル | 用途 |
|---|---|
| `ogp.png`（または `ogp.jpg`） | SNS でリンクを共有したときに出す画像。1200×630 ピクセルがおすすめです |
| `favicon.svg` | ブラウザのタブのアイコン |
| `favicon.png` | ブラウザのタブ（`favicon.svg` がないとき）と、ホーム画面のアイコン。180×180 ピクセル以上の正方形がおすすめです |

どれも、置かなければ EventPost の既定の画像を使います。置き方と、OGP の画像を URL で指定するやり方は、README の「SNS での見え方（OGP）」と「ファビコン」を見てください。
